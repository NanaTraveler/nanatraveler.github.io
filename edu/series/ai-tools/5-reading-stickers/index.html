책 제목과 한 마디 느낌을 적으면 스티커 한 칸이 채워져요. 판을 다 채우면 새 판이 시작됩니다. 위에서 먼저 써 보고, 아래 순서대로 아이와 같이 만들어 보세요.

한 마디 느낌 (하나 고르기)

읽은 책 기록

    아직 기록이 없어요. 첫 책을 붙여 보세요.

    AI 에 "이 책들로 독후 질문 3개 만들어 줘"라고 붙여 넣을 때 써요.

    30분

    아이랑 만드는 순서

    1. 아이가 정할 질문

    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

    1. 판은 몇 칸으로 할까? (10칸, 20칸, 30칸)
    2. 스티커에는 무엇이 보이면 좋을까? (책 제목 첫 글자, 날짜, 번호)
    3. 책을 다 읽으면 어떤 느낌 말을 고를 수 있게 할까? 4~6개.
    4. 잘못 붙였을 때 지울 수 있게 할까?
    5. 판을 다 채우면 화면에 뭐라고 나올까?

    2. 챗GPT 등에 붙여 넣을 프롬프트

    초등학생이 쓰는 '독서 기록 스티커판'을 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. [칸 수]칸짜리 스티커판을 5칸씩 줄 맞춰 보여 준다. 빈칸에는 번호만 옅게 쓴다.
2. 책 제목을 쓰고 느낌을 하나 고르면 다음 빈칸이 채워진다. 느낌: [느낌 말 4~6개]
3. 채워진 칸에는 [책 제목 첫 글자 / 날짜 / 번호]를 보여 준다.
4. 아래에 읽은 책 목록을 날짜, 제목, 느낌 순으로 보여 주고, [지우기 버튼을 둔다 / 두지 않는다].
5. 판을 다 채우면 "[아이가 정한 말]"을 크게 띄우고 새 판을 시작한다. 지난 판 수도 보여 준다.
6. 기록은 이 브라우저에만 저장(localStorage)해 줘. 이름이나 학교 같은 개인정보는 받지 마.
7. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.

    3. 에러가 나면 이렇게 물어보기

    휴대폰에서 스티커 칸이 화면 밖으로 넘쳐. 칸이 화면 너비에 맞게 줄어들도록 고친 코드 전체를 다시 줘.
    제목을 안 쓰고 버튼을 눌러도 스티커가 붙어. 제목이 비어 있으면 "책 제목을 적어 주세요"라고 알려 주도록 고친 코드 전체를 다시 줘.
    새로고침하면 붙인 스티커가 사라져. localStorage에 저장하고 다시 불러오도록 고친 코드 전체를 다시 줘.

    4. 30분 시간표

    시간할 일
    0~5분완성본에 최근 읽은 책 하나를 붙여 본다.
    5~12분질문 5개에 답하고 프롬프트 [ ]를 채운다.
    12~20분챗GPT에 붙여 넣고 books.html 로 저장해 연다.
    20~27분책 두세 권을 붙여 보고, 아이가 이상한 점 하나를 에러 문장으로 고친다.
    27~30분오늘 붙인 책 중 하나를 골라 한 문장으로 이야기하고 끝.
    개인정보

    이 페이지는 아이 개인정보를 받지 않습니다. 책 제목과 느낌만 지금 쓰는 기기의 브라우저에 남고, 브라우저 기록을 지우면 함께 사라져요. 기록을 AI 에 붙여 넣을 때도 아이 이름·학교는 빼는 걸 권합니다.
