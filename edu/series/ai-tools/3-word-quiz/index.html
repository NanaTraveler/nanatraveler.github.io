아이랑 AI로 만드는 툴 · 3회

영어 단어 퀴즈

4지선다로 10문제. 틀린 단어만 모아 다시 풀고, 우리 집 단어를 직접 넣을 수 있어요. 위에서 먼저 써 보고, 아래 순서대로 아이와 같이 만들어 보세요.

완성본 써 보기

우리 집 단어 넣기

넣은 단어도 문제에 섞여 나와요.

아이랑 만드는 순서

1. 아이가 정할 질문

답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

  1. 문제는 몇 개 낼까? 영어를 보고 뜻을 고를까, 뜻을 보고 영어를 고를까?
  2. 보기는 몇 개가 좋을까?
  3. 틀리면 어떻게 할까? (정답 보여 주기 / 다시 풀기)
  4. 어떤 단어 10개로 시작할까? (요즘 배우는 단어나 좋아하는 것)
  5. 다 맞히면 화면에 뭐라고 나올까?

2. 챗GPT 등에 붙여 넣을 프롬프트

초등학생이 쓰는 '영어 단어 퀴즈'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 단어 목록: [영어=뜻, 영어=뜻, ... 10개]
2. 문제는 [개수]개, [영어 보고 뜻 고르기 / 뜻 보고 영어 고르기] 방식이다.
3. 보기는 [개수]개이고, 오답 보기는 단어 목록에서 섞어서 만든다.
4. 틀리면 [아이가 정한 방법]으로 한다.
5. 끝나면 점수와 틀린 단어를 보여 주고, '틀린 것만 다시' 버튼을 만든다.
6. 다 맞히면 "[아이가 정한 말]"을 크게 띄운다.
7. 단어를 직접 추가할 수 있게 하고, 이 브라우저에만 저장(localStorage)해 줘. 개인정보는 받지 마.

3. 에러가 나면 이렇게 물어보기

보기에 같은 뜻이 두 번 나와. 보기가 겹치지 않게 고친 코드 전체를 다시 줘.
화면이 하얗게 나오고 아무것도 안 보여. 코드 전체를 다시 확인해서 HTML 파일 하나로, 처음부터 끝까지 빠짐없이 다시 써 줘.
버튼을 눌러도 아무 일이 안 일어나. 왜 그런지 초등학생도 알 수 있게 한 줄로 설명하고, 고친 코드 전체를 다시 줘.

4. 30분 시간표

0~5분완성본을 한 판 풀어 보고, 우리 단어 10개를 아이가 고른다.
5~12분질문 5개에 답하고 프롬프트 [ ]를 채운다.
12~20분챗GPT에 붙여 넣고 quiz.html 로 저장해 연다.
20~27분부모가 한 판 풀어 보고, 아이가 이상한 점 하나를 에러 문장으로 고친다.
27~30분가족 중 한 명에게 문제를 내 보게 하고 끝.
