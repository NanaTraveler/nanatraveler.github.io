    30분
    
      
    아이랑 만드는 순서
    
    
    
    
    
      
    
        
    1. 아이가 정할 질문
    
        
    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.
    
        
    1. 동화 재료 칸은 무엇으로 할까? (주인공·장소·일어나는 일 말고 더 넣고 싶은 칸이 있어?)
    2. 칸마다 어떤 재료를 넣을까? 칸마다 5개씩.
    3. 섞어 뽑기 버튼 이름은 뭐라고 할까?
    4. AI한테 꼭 지키라고 할 약속 하나는? (예: 무서운 장면 없이)
    5. 동화는 몇 분짜리가 좋을까?
    
      
    
      
    
        
    2. 챗GPT 등에 붙여 넣을 프롬프트
    
        
    초등학생이 쓰는 '잠자리 동화 재료 뽑기'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 재료 칸을 만든다: [칸 이름들]. 칸마다 재료를 버튼으로 보여 준다: [칸별 재료 5개씩].
2. 버튼을 누르면 칸마다 하나씩 고른 표시가 된다.
3. '[섞어 뽑기 버튼 이름]'을 누르면 칸마다 하나씩 무작위로 골라 준다.
4. 고른 재료로 아래 문장을 완성해 화면 아래 상자에 보여 준다.
   "잠자리에서 읽어 줄 짧은 동화를 써 줘. 주인공은 ○, 장소는 ○, 일어나는 일은 ○. 소리 내어 읽으면 [몇 분]쯤 되는 길이로. [AI가 지킬 약속]. 실제 사람 이름이나 학교는 넣지 마."
5. '복사' 버튼을 누르면 그 문장이 복사되고 '복사했어요'가 잠깐 뜬다.
6. 마음에 든 조합은 '저장'을 눌러 이 브라우저에만(localStorage) 10개까지 남기고, 지울 수 있게 해 줘.
7. 이름이나 학교 같은 개인정보는 받지 마.
8. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.
    
      
    
      
    
        
    3. 에러가 나면 이렇게 물어보기
    
        
    섞어 뽑기를 눌러도 버튼의 고른 표시가 그대로야. 무작위로 뽑힌 재료 버튼에 고른 표시가 옮겨 가도록 고친 코드 전체를 다시 줘.
    
        
    복사 버튼을 눌러도 복사가 안 돼. 파일로 열었을 때도 복사되게 하고, 그래도 안 되면 문장 전체를 선택해 주도록 고친 코드 전체를 다시 줘.
    
        
    새로고침하면 저장한 조합이 다 사라져. localStorage 에 저장하고 처음 열 때 불러오도록 고친 코드 전체를 다시 줘.
    
      
    
      
    
        
    4. 30분 시간표
    
        
    시간할 일
    0~5분완성본으로 섞어 뽑기를 한 번 하고, 나온 문장을 AI에 넣어 동화를 받아 본다.
    5~12분질문 5개에 답하고 칸별 재료를 아이가 정해 프롬프트 [ ]를 채운다.
    12~20분챗GPT에 붙여 넣고 story.html 로 저장해 연다.
    20~27분아이 도구로 뽑은 문장을 AI에 넣어 보고, 이상한 점 하나를 에러 문장으로 고친다.
    27~30분오늘 밤 읽을 조합 하나를 저장하고 끝.
    
      
    
    
    
    
    
      개인정보
      
    이 페이지는 아이 개인정보를 받지 않습니다. 고른 재료와 저장한 조합만 지금 쓰는 기기의 브라우저에 남고, 브라우저 기록을 지우면 함께 사라져요. 재료 칸에도 아이 실제 이름·학교·사는 곳은 넣지 마세요.
    
    
    
    
    
      쓰는 요령
      
    AI가 쓴 동화는 읽어 주기 전에 어른이 한 번 훑어보세요. 마음에 걸리는 장면이 있으면 "그 장면은 빼고 다시 써 줘"라고 한 줄만 보내면 됩니다.
