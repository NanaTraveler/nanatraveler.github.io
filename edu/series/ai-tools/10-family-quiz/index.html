아이랑 AI로 만드는 툴 · 10회

아이가 문제를 내고 어른이 푸는 날도 만들 수 있는 퀴즈쇼입니다. 문제는 직접 쓰거나, AI에게 정해진 모양으로 만들어 달라고 해서 통째로 붙여 넣습니다. 진행자가 정답을 공개하고 맞힌 팀만 눌러 점수를 줍니다.

저장하지 않음

1. 문제

    문제가 없어요. 아래에서 넣거나 붙여 넣으세요.

    문제 하나 넣기

    정답 보기 앞의 동그라미를 눌러 고릅니다.

    AI로 만든 문제 붙여 넣기

    아래 문장을 복사해 챗GPT 등에 넣고, 나온 답을 통째로 붙여 넣으세요. [ ]만 바꾸면 됩니다.

    초등학생과 가족이 함께 푸는 4지선다 퀴즈를 [주제]로 [문제 수]문제 만들어 줘. 정답은 하나, 보기는 짧게. 사실이 확실하지 않은 문제는 빼 줘. 사람 이름은 넣지 마. 아래 모양 그대로만 써 줘. 정답 보기 끝에 * 를 붙여.

Q: 질문
1) 보기
2) 보기 *
3) 보기
4) 보기

    이 페이지는 문제를 저장하지 않아요. 다음에 또 쓰려면 "글로 복사"를 눌러 메모장에 두었다가 다시 붙여 넣으세요.

    2. 팀

    팀 이름은 "파랑팀"처럼 짓고, 실제 이름은 넣지 않아요.

    1 / 5진행자 화면

    맞힌 팀 누르기 (+1점)

    정답을 공개한 뒤 맞힌 팀을 모두 누릅니다. 잘못 눌렀으면 한 번 더 누르면 취소돼요.

    끝!

      30분

      아이랑 만드는 순서

      1. 아이가 정할 질문

      답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

      1. 몇 팀이 겨룰까? 팀 이름은 어떻게 부를까?
      2. 한 판에 몇 문제를 낼까? 문제는 누가 낼까?
      3. 맞히면 몇 점? 틀리면 점수를 뺄까, 그냥 둘까?
      4. 정답을 공개할 때 화면이 어떻게 바뀌면 좋을까?
      5. 다 끝나면 화면에 뭐라고 나올까? 같은 점수면 어떻게 할까?

      2. 챗GPT 등에 붙여 넣을 프롬프트

      가족이 함께 하는 '우리 가족 퀴즈쇼'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 문제 입력 칸: 질문 하나와 보기 4개, 정답 고르기. '문제 더하기'로 목록에 쌓는다.
2. 팀은 [팀 수]팀, 이름은 [팀 이름들]. 한 판은 [문제 수]문제.
3. '시작'을 누르면 문제를 하나씩 크게 보여 주고 보기 4개를 큰 칸으로 보여 준다.
4. '정답 공개'를 누르면 [정답 공개 때 바뀌는 모습].
5. 팀 버튼을 누르면 그 팀에 [맞혔을 때 점수]점. 다시 누르면 취소.
6. 마지막 문제가 끝나면 점수 순서대로 보여 주고 "[끝났을 때 말]"을 띄운다. 같은 점수는 [같은 점수일 때 규칙].
7. 이름이나 사진 같은 개인정보는 받지도 저장하지도 마. 문제는 저장하지 않아도 돼.
8. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.

      3. 에러가 나면 이렇게 물어보기

      정답 공개를 누르기 전에도 팀 버튼을 누르면 점수가 올라가. 정답을 공개한 뒤에만 팀 버튼이 눌리도록 고친 코드 전체를 다시 줘.
      다음 문제로 넘어가도 지난 문제의 정답 표시가 남아 있어. 문제를 바꿀 때 정답 표시와 팀 버튼 눌림을 초기화하도록 고친 코드 전체를 다시 줘.
      마지막 문제가 끝났는데 아무것도 안 나와. 마지막 문제 다음에는 점수판 화면으로 넘어가도록 고친 코드 전체를 다시 줘.

      4. 30분 시간표

      시간할 일
      0~5분완성본의 예시 문제로 한 판 해 본다. 아이가 진행자를 맡는다.
      5~12분질문 5개에 답하고, 아이가 직접 문제 3개를 지어 종이에 적는다.
      12~20분프롬프트를 챗GPT에 붙여 넣고 family-quiz.html 로 저장해 연다.
      20~27분아이가 지은 문제를 넣고 가족과 한 판. 이상한 점 하나를 에러 문장으로 고친다.
      27~30분다음 퀴즈쇼 주제와 진행자를 정하고 끝.
      개인정보

      이 페이지는 아무것도 저장하지 않습니다. 문제·팀 이름·점수는 페이지를 닫으면 사라지고, 어디로도 보내지 않아요. "엄마가 좋아하는 색"처럼 가족 이야기로 문제를 내도 이 기기 밖으로 나가지 않습니다.

      쓰는 요령

      AI가 만든 문제는 틀린 정답이 섞일 수 있어요. 시작 전에 아이와 정답을 한 번 같이 확인하는 것 자체를 퀴즈 준비 시간으로 쓰면 됩니다. 점수 차가 크게 나면 마지막 문제를 3점으로 하는 우리 집 규칙도 좋아요.
