    단계

    네 단계는 이렇게 다릅니다

    단계문제 모양
    1 순서대로고른 단을 ×1부터 ×9까지 차례로. 9문제.
    2 섞어서고른 단의 아홉 문제를 순서만 섞어서.
    3 여러 단두 단 이상을 골라 섞은 것 중 10문제. 같은 문제는 한 판에 한 번만.
    4 빈칸6 × □ = 42 처럼 곱하는 수를 거꾸로 찾기. 한 단이면 9문제, 여러 단이면 10문제.

    어느 단계로 언제 넘어갈지는 아이와 정하세요. 예를 들어 "다 맞힌 날이 두 번이면 다음 단계"처럼 우리 집 규칙을 정해 두면 됩니다.

    30분

    아이랑 만드는 순서

    1. 아이가 정할 질문

    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

    1. 단계는 몇 개로 할까? 단계마다 문제 모양은 어떻게 다르게 할까?
    2. 한 판에 몇 문제를 낼까?
    3. 틀리면 어떻게 할까? 정답을 보여 주고 넘어갈까, 맞힐 때까지 다시 낼까?
    4. 다 풀면 화면에 뭐라고 나올까?
    5. 기록은 무엇으로 남길까? 걸린 시간, 맞힌 개수, 둘 다?

    2. 챗GPT 등에 붙여 넣을 프롬프트

    첫 AI 앱 때 만든 구구단 게임 코드가 있으면 프롬프트 맨 앞에 그 코드를 붙이고 "이 코드에 아래 기능을 더해 줘"라고 시작해도 됩니다.

    초등학생이 쓰는 '구구단 달리기'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 단(2~9단)을 버튼으로 고른다. 단계 버튼도 둔다: [단계 이름과 문제 모양].
2. '출발'을 누르면 시간이 0.1초 단위로 올라가고, 문제를 하나씩 크게 보여 준다. 한 판은 [문제 수]문제.
3. 화면에 0~9 숫자 버튼과 '지우기', '확인'을 만든다. 키보드 숫자와 엔터로도 된다.
4. 틀리면 [틀렸을 때 할 일].
5. 마지막 문제를 풀면 시간을 멈추고 "[다 풀었을 때 말]"과 걸린 시간, 맞힌 개수를 보여 준다.
6. 단·단계마다 내 최고 기록을 [기록으로 남길 것] 기준으로 보여 주고, 새 기록이면 몇 초 빨라졌는지 알려 준다.
7. 틀린 문제만 모아 다시 푸는 버튼을 만든다.
8. 기록은 이 브라우저에만 저장(localStorage)하고, 이름이나 학교 같은 개인정보는 받지 마.
9. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.

    3. 에러가 나면 이렇게 물어보기

    정답을 넣었는데 틀렸다고 나와. 입력한 글자를 숫자로 바꿔서 정답과 비교하도록 고친 코드 전체를 다시 줘.
    한 판에 같은 문제가 두 번 나와. 문제를 섞을 때 겹치지 않게 뽑도록 고친 코드 전체를 다시 줘.
    마지막 문제를 풀어도 시간이 계속 올라가. 마지막 문제를 풀면 타이머를 멈추고 걸린 시간을 보여 주도록 고친 코드 전체를 다시 줘.

    4. 30분 시간표

    시간할 일
    0~5분완성본으로 아이가 자신 있는 단을 1단계로 한 번 달려 본다.
    5~12분질문 5개에 답하고 프롬프트 [ ]를 채운다.
    12~20분챗GPT에 붙여 넣고 gugudan-race.html 로 저장해 연다.
    20~27분아이가 만든 게임으로 한 판 풀어 보고, 이상한 점 하나를 에러 문장으로 고친다.
    27~30분다음 단계로 넘어갈 우리 집 규칙을 하나 정하고 끝.
    개인정보

    이 페이지는 아이 개인정보를 받지 않습니다. 고른 단·단계와 걸린 시간, 맞힌 개수만 지금 쓰는 기기의 브라우저에 남고, 브라우저 기록을 지우면 함께 사라져요.
