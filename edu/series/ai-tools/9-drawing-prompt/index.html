사람 이름·학교 이름은 넣지 않아요. 우리 집 낱말은 눌러서 지울 수 있어요.

다 그린 주제

    아직 없어요. 다 그리면 "다 그렸어요"를 눌러 남겨 보세요.

    30분

    아이랑 만드는 순서

    1. 아이가 정할 질문

    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

    1. 뽑기 칸은 몇 개로 할까? 칸 이름은? (예: 누가·어디서·무엇을·도전)
    2. 칸마다 들어갈 낱말 8개씩 말해 볼까? 웃긴 것, 엉뚱한 것도 좋아.
    3. 뽑을 때 화면이 어떻게 보이면 좋을까? 글자가 빠르게 바뀌다 멈추기, 바로 나오기?
    4. 마음에 드는 칸은 그대로 두는 '고정' 버튼이 있으면 좋겠어?
    5. 다 그린 주제는 어디에 모아 둘까?

    2. 챗GPT 등에 붙여 넣을 프롬프트

    초등학생이 쓰는 '오늘 그릴 것 뽑기'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 뽑기 칸은 [칸 개수]개: [칸 이름들].
2. 칸마다 낱말 목록을 넣어 줘:
[칸 이름1]: [낱말 8개]
[칸 이름2]: [낱말 8개]
(칸 수만큼)
3. '뽑기' 버튼을 누르면 [뽑을 때 보이는 모습]. 칸마다 낱말 하나씩 무작위로 고른다.
4. 칸마다 '고정' 버튼을 둔다. 고정한 칸은 다시 뽑아도 바뀌지 않는다.
5. 뽑은 낱말을 한 문장으로 이어서 크게 보여 준다. 예: "구름 위에서 케이크를 굽는 공룡".
6. '다 그렸어요'를 누르면 그 주제와 날짜를 [모아 둘 곳]에 쌓는다.
7. 저장은 이 브라우저에만(localStorage) 하고, 이름이나 학교 같은 개인정보는 받지 마.
8. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.

    3. 에러가 나면 이렇게 물어보기

    고정 버튼을 눌렀는데도 뽑기를 하면 그 칸 낱말이 바뀌어. 고정한 칸은 건너뛰고 나머지만 뽑도록 고친 코드 전체를 다시 줘.
    뽑기를 여러 번 눌러도 같은 낱말이 연달아 나와. 바로 전에 나온 낱말은 한 번 빼고 뽑도록 고친 코드 전체를 다시 줘.
    새로고침하면 다 그린 주제 목록이 사라져. localStorage 에 저장하고 처음 열 때 불러오도록 고친 코드 전체를 다시 줘.

    4. 30분 시간표

    시간할 일
    0~5분완성본으로 두세 번 뽑아 보고, 제일 웃긴 주제를 골라 둔다.
    5~13분질문 5개에 답하고 칸마다 낱말 8개를 아이가 말한다.
    13~20분챗GPT에 붙여 넣고 drawing-picker.html 로 저장해 연다.
    20~27분아이가 만든 뽑기판으로 주제를 뽑고, 이상한 점 하나를 에러 문장으로 고친다.
    27~30분뽑은 주제를 종이 구석에 적어 두고 끝. 그림은 다음에 그려도 된다.
    개인정보

    이 페이지는 아이 개인정보를 받지 않습니다. 더한 낱말과 다 그린 주제만 지금 쓰는 기기의 브라우저에 남고, 브라우저 기록을 지우면 함께 사라져요. 아이 그림 사진을 AI에 올리는 기능은 넣지 않았습니다.

    쓰는 요령

    도전 규칙이 부담스러워 보이면 '도전' 칸을 '없음'으로 고정해도 됩니다. 다 그린 그림은 잘 그렸는지보다 "이 공룡은 무슨 케이크를 굽는 거야?"처럼 그림 속 이야기를 물어봐 주세요.
