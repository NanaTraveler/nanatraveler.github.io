용돈 기록장

받은 돈·쓴 돈을 적으면 남은 돈과 목표까지 남은 금액이 바로 나와요. 위에서 먼저 써 보고, 아래 순서대로 아이와 같이 만들어 보세요.

완성본 써 보기
남은 돈0원
이번 달 받은 돈0원
이번 달 쓴 돈0원
모으는 목표
목표 금액을 적으면 얼마나 모였는지 보여 줘요.

    아직 기록이 없어요. 첫 용돈부터 적어 보세요.

    아이랑 만드는 순서

    1. 아이가 정할 질문

    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

    1. 받은 돈과 쓴 돈을 무슨 색으로 보여 줄까?
    2. 돈을 쓸 때 고를 수 있는 종류는 뭐가 있으면 좋을까? (예: 간식, 장난감, 저금)
    3. 모으고 싶은 목표는 얼마고, 다 모이면 화면에 뭐라고 나올까?
    4. 남은 돈이 0원보다 적어지면 어떻게 알려 줄까?

    2. 챗GPT 등에 붙여 넣을 프롬프트

    초등학생이 쓰는 '용돈 기록장'을 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. '받은 돈'과 '쓴 돈'을 골라서 무엇인지와 금액을 적으면 목록에 쌓인다.
2. 맨 위에 '남은 돈'을 크게 보여 준다.
3. 받은 돈은 [색], 쓴 돈은 [색]으로 보여 준다.
4. 쓴 돈의 종류는 [종류1, 종류2, 종류3] 중에서 고른다.
5. 목표 금액은 [금액]원이고, 다 모이면 "[아이가 정한 말]"이라고 크게 띄운다.
6. 남은 돈이 0원보다 적어지면 [아이가 정한 방법]으로 알려 준다.
7. 기록은 이 브라우저에만 저장되게 해 줘(localStorage). 이름 같은 개인정보는 받지 마.

    3. 에러가 나면 이렇게 물어보기

    금액을 적었는데 남은 돈 계산이 이상해. 숫자가 글자로 더해지는 것 같아. 어디가 문제인지 알려 주고 고친 코드 전체를 다시 줘.
    화면이 하얗게 나오고 아무것도 안 보여. 코드 전체를 다시 확인해서 HTML 파일 하나로, 처음부터 끝까지 빠짐없이 다시 써 줘.
    버튼을 눌러도 아무 일이 안 일어나. 왜 그런지 초등학생도 알 수 있게 한 줄로 설명하고, 고친 코드 전체를 다시 줘.

    4. 30분 시간표

    0~5분위 완성본을 같이 써 보고 "우리는 뭘 바꿀까?" 한 가지만 고른다.
    5~12분질문 4개에 아이가 답하고, 프롬프트 [ ] 자리를 채운다.
    12~20분챗GPT에 붙여 넣고, 나온 코드를 메모장에 붙여 allowance.html 로 저장해 연다.
    20~27분이상한 곳을 아이가 찾고, 에러 문장으로 한 번 고친다.
    27~30분이번 주 받은 용돈을 진짜로 하나 적어 보고 끝.
