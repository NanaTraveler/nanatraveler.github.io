아이랑 만드는 순서

1. 아이가 정할 질문

답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

  1. 기분을 몇 가지 날씨로 나눌까? 각각 어떤 기분이야?
  2. 날씨마다 카드 바탕색은 무슨 색이 좋을까?
  3. 카드에 한 줄을 쓸 수 있게 할까? 몇 글자까지?
  4. 일주일이 다 차면 화면에 뭐라고 보여 줄까?

2. 챗GPT 등에 붙여 넣을 프롬프트

초등학생이 쓰는 '오늘의 기분 날씨 카드'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 기분을 날씨로 고른다: [날씨1=기분], [날씨2=기분], [날씨3=기분], [날씨4=기분]
2. 날씨 그림은 이모지 말고 SVG로 간단하게 그려 줘.
3. 고르면 오늘 날짜와 함께 카드가 나오고, 바탕색은 [날씨별 색]으로 한다.
4. 카드에 한 줄을 [글자 수]자까지 쓸 수 있다.
5. '남기기'를 누르면 최근 7일 칸에 그날 날씨 그림이 쌓인다. 7일이 다 차면 "[아이가 정한 말]"을 보여 준다.
6. 기록은 이 브라우저에만 저장(localStorage)하고, 이름·학교 같은 개인정보는 받지 마.

3. 에러가 나면 이렇게 물어보기

날짜가 하루씩 밀려서 나와. 한국 시간 기준으로 오늘 날짜가 나오게 고친 코드 전체를 다시 줘.
화면이 하얗게 나오고 아무것도 안 보여. 코드 전체를 다시 확인해서 HTML 파일 하나로, 처음부터 끝까지 빠짐없이 다시 써 줘.
버튼을 눌러도 아무 일이 안 일어나. 왜 그런지 초등학생도 알 수 있게 한 줄로 설명하고, 고친 코드 전체를 다시 줘.

4. 30분 시간표

시간할 일
0~5분완성본에서 오늘 날씨를 하나 골라 보고, 우리 집 날씨 종류를 정한다.
5~12분질문 4개에 아이가 답하고 프롬프트 [ ]를 채운다.
12~20분챗GPT에 붙여 넣고 mood.html 로 저장해 연다.
20~27분색이나 그림이 마음에 안 드는 곳 하나를 아이 말로 고쳐 달라고 한다.
27~30분오늘 카드를 하나 남기고, 내일 또 열어 볼 시간을 정한다.
개인정보

이 페이지는 아이 개인정보를 받지 않습니다. 기록은 지금 쓰는 기기의 브라우저에만 남고, 브라우저 기록을 지우면 함께 사라져요. 챗GPT에도 아이 이름·학교·사진은 넣지 않는 걸 권합니다.
