    아이랑 만드는 순서

    1. 아이가 정할 질문

    답은 아이가 정하고, 부모는 받아 적기만 합니다. 정한 답을 아래 프롬프트의 [ ] 자리에 넣어요.

    1. 타이머로 어떤 일을 해 볼까? 3~5개.
    2. 시간은 몇 분짜리를 고를 수 있게 할까?
    3. 시간이 끝나면 화면에 뭐라고 나올까?
    4. 시간 안에 끝내면 뭐라고 나올까?
    5. 남은 시간을 숫자로만 보여 줄까, 줄어드는 막대도 같이 보여 줄까?

    2. 챗GPT 등에 붙여 넣을 프롬프트

    초등학생이 쓰는 '타이머 달리기'를 HTML 파일 하나로 만들어 줘. 브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

기능:
1. 할 일 버튼을 보여 준다: [할 일 3~5개]. 하나를 누르면 고른 표시가 된다.
2. 시간 버튼을 보여 준다: [고를 수 있는 시간들]. 기본은 [기본 시간].
3. '출발'을 누르면 남은 시간이 분:초로 크게 줄어들고, [줄어드는 막대도 / 숫자만] 보여 준다.
4. '다 했어!'를 누르면 걸린 시간을 기록하고 "[시간 안에 끝냈을 때 말]"을 띄운다.
5. 시간이 0이 되면 "[시간이 끝났을 때 말]"을 띄우고, 그 뒤로는 넘친 시간을 +로 세어 계속 보여 준다.
6. 할 일마다 가장 빠른 기록을 보여 주고, 새 기록과 비교해 몇 초 빨라졌는지 알려 준다.
7. 기록은 이 브라우저에만 저장(localStorage)해 줘. 이름이나 학교 같은 개인정보는 받지 마.
8. 그림 문자(이모지) 대신 글자와 네모 칸으로만 꾸며 줘.

    3. 에러가 나면 이렇게 물어보기

    출발을 두 번 누르면 시간이 두 배로 빨리 줄어들어. 출발을 여러 번 눌러도 타이머가 하나만 돌도록 고친 코드 전체를 다시 줘.
    다른 창을 보다가 돌아오면 시간이 멈춰 있어. 시작한 시각을 기억해 두고 지금 시각과 빼서 남은 시간을 계산하도록 고친 코드 전체를 다시 줘.
    시간이 끝나도 아무 일도 안 일어나. 0초가 되면 메시지를 띄우고 넘친 시간을 +로 세도록 고친 코드 전체를 다시 줘.

    4. 30분 시간표

    시간할 일
    0~5분완성본으로 1분짜리 달리기를 한 번 해 본다. (예: 신발 정리)
    5~12분질문 5개에 답하고 프롬프트 [ ]를 채운다.
    12~20분챗GPT에 붙여 넣고 timer.html 로 저장해 연다.
    20~27분아이가 만든 타이머로 한 번 달려 보고, 이상한 점 하나를 에러 문장으로 고친다.
    27~30분내일 아침에 해 볼 할 일 하나를 정하고 끝.
    개인정보

    이 페이지는 아이 개인정보를 받지 않습니다. 할 일 이름과 걸린 시간만 지금 쓰는 기기의 브라우저에 남고, 브라우저 기록을 지우면 함께 사라져요.
