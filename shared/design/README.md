# NanaTraveler 자료 디자인 규칙서 (v1.0 · 2026-11-16)

무료 자료를 만들 때 이 문서와 견본 3종만 보고 따라 한다. 새 디자인을 만들지 않는다.
목표는 하나다. 어느 계정의 어느 자료를 열어도 같은 집에서 나온 것처럼 보이게 한다.

## 방향

1. **색판 표지 + 중립 본문.** 계정색은 표지 한 면에 몰아 쓰고, 본문은 흰 바탕·먹색 글자로 둔다.
2. **글자와 여백, 선으로 나눈 격자.** 장식(그라데이션·번짐·이모지·아이콘·도장)은 쓰지 않는다.
3. **휴대폰에서 바로 읽힌다.** 요약 숫자가 먼저, 자세한 표가 그다음. 다크 모드는 자동으로 따라온다.

## 파일

| 파일 | 쓰임 |
|---|---|
| `tokens.css` | 색·크기·간격·부품의 원본. 여기만 고친다 |
| `template-app.html` | 웹앱·게임·계산기 견본 |
| `template-dashboard.html` | 한눈표(대시보드) 견본 |
| `template-guide.html` | 요약서 견본 (A4 인쇄·PDF 포함) |
| `sync.py` | `tokens.css` 를 HTML 의 `tokens:start ~ tokens:end` 구간에 다시 넣는다 |
| `preview/` | 견본을 세 계정색으로 찍은 화면. 결과물을 이것과 나란히 놓고 비교한다 |

## 만드는 순서

1. 견본을 고른다 (아래 표). 파일을 통째로 복사한다. 예: `chart/apps/position-size/index.html`
2. `<html data-account="…">` 를 `edu` / `chart` / `travel` 로 맞춘다.
3. 표지 문구, 본문, 하단 정보를 바꾼다.
4. 화면을 찍어 확인한다 (아래 "확인").
5. 루트 `index.html` 의 해당 계정 `<!-- …:list -->` 바로 아래에 항목 한 줄을 넣는다.

| 만들 것 | 견본 | 표지의 자료 종류 |
|---|---|---|
| 입력하면 결과가 나오는 것 (계산기, 퀴즈, 게임, 생성기) | `template-app.html` | 웹앱 |
| 여러 항목을 비교·필터하는 표와 차트 | `template-dashboard.html` | 대시보드 |
| 읽는 글, 순서 안내, 체크리스트, PDF 로 줄 것 | `template-guide.html` | 요약서 |

둘에 걸치면 **사용자가 가장 먼저 하는 행동**으로 고른다. 숫자를 넣는다 → 웹앱, 훑어본다 → 대시보드, 읽는다 → 요약서.

## 바꿔도 되는 곳 · 바꾸면 안 되는 곳

**바꿔도 된다**

- `data-account` 값, `<title>`, `<meta name="description">`
- 표지와 하단 정보의 **글자**
- `<main>` 안의 내용: 구획(`.sec`)을 더하고 빼고 순서를 바꾼다
- `tokens:end` 아래 "이 파일만의 배치" CSS 와 `<script>`

**바꾸면 안 된다**

- `tokens:start ~ tokens:end` 사이. 고칠 일이 있으면 `tokens.css` 를 고치고 `python3 shared/design/sync.py <파일>` 로 다시 넣는다
- 표지 헤더의 구조와 순서: 계정 표식(@핸들 · 분야) → 자료 종류 → 제목 → 한 줄 설명 → 기준일
- 하단 정보의 다섯 항목: @핸들, 기준일, 출처, 고지 한 줄, nanatraveler.github.io 링크
- 색 값 직접 쓰기. `#` 으로 시작하는 색을 새로 쓰지 않고 `var(--…)` 만 쓴다
- 글자 크기·간격을 단계 밖 값으로 쓰기 (`--t-12 … --t-40`, `--s-1 … --s-8`)
- 외부 글꼴·스크립트·이미지 주소. 파일 하나로 끝나야 한다

## 색

| 계정 | 표지 면 `--accent` | 본문 강조 글자 (라이트 / 다크) | 옅은 바탕 (라이트 / 다크) | 차트 주 계열 (라이트 / 다크) |
|---|---|---|---|---|
| edu | `#a86400` | `#8f5500` / `#f2b24a` | `#f8eeda` / `#30240e` | `#a86400` / `#c28419` |
| chart | `#c41d37` | `#b3162f` / `#ff7a8a` | `#fceaed` / `#35181d` | `#c41d37` / `#e2586b` |
| travel | `#00806a` | `#006b59` / `#45d1b0` | `#e1f2ee` / `#0f2c27` | `#00806a` / `#22ab8c` |

공통: 보조색 `--second` `#2f6fd0`(다크 `#5a8ee6`), 바탕 `#f4f5f6`, 면 `#ffffff`, 글자 `#14171a`. 다크 바탕 `#0f1113`.
표지 면 색은 흰 글자와 4.5:1 이상이 되도록 원래 색보다 한 단계 깊게 잡았다.

**강조색은 표지를 빼고 한 화면에 세 곳까지만 쓴다.**

1. 가장 중요한 버튼 하나 (`.btn--accent`)
2. 가장 중요한 결과 숫자 하나 (`.key-value`) 또는 요약 콜아웃 하나 (`.callout--accent`)
3. 차트의 주 계열

나머지는 전부 먹색과 회색이다. 고른 필터, 일반 버튼, 표 머리, 구분선에 강조색을 쓰지 않는다.
상태색(`--good` `--warn` `--bad`)은 계정색과 별개이고, 항상 글자("주의", "입력 확인")와 함께 쓴다.
차트 계정에서 상승·하락은 `--up`(빨강) `--down`(파랑)을 쓴다.

| 핵심 숫자 | `.key` | 화면에 하나 |

## 표

- 휴대폰에서 **5열까지**. 넘으면 `<table class="table--stack">` 과 `td data-label="…"` 로 줄마다 묶는다.
- 머리글은 6자 이내. 길면 표 아래 `.small` 로 풀어 쓴다.
- 숫자 열은 `class="num"`(오른쪽 정렬, 자릿수 맞춤). 단위는 머리글이나 표 아래에 한 번만.
- 줄바꿈되면 안 되는 칸은 `class="nowrap"`.
- 표는 항상 `<div class="table-wrap">` 안에 넣는다. 세로선·줄무늬 배경을 넣지 않는다.

## 차트

- 인라인 SVG 로 직접 그린다. 라이브러리를 부르지 않는다.
- SVG 는 **실제 폭으로 그린다** (견본의 `drawChart` 처럼 `clientWidth` 를 재서). `viewBox` 로 줄이면 글자가 작아져 못 읽는다.
- 색은 최대 2계열: `--chart-1`(계정색)과 `--chart-2`(보조색). 그 밖의 것은 `--chart-mute`. 계열이 2개 이상이면 `.legend` 를 붙인다.
- 값은 막대 끝·선 끝에 직접 적는다(`.c-value`). 글자는 먹색이고 계열색을 입히지 않는다.
- y축은 하나만. 단위가 다른 두 값은 차트를 둘로 나눈다.
- 막대는 0 에서 시작하고 끝만 4px 둥글린다. 선은 2px. 격자는 `--chart-grid` 로 옅게.
- 제목(`.chart-title`)과 단위·기준(`.chart-note`)을 반드시 적는다. 같은 숫자를 볼 수 있는 표를 함께 둔다.
- 막대·점에 누르면 뜨는 설명(`.tip`)을 붙인다.
- 3D, 원그래프 5조각 초과, 그림자, 그라데이션 채움 금지.

## 요약서(PDF)

- 표지에 `class="cover cover--page"` 를 쓴다. 인쇄하면 표지가 A4 한 장을 꽉 채우고 본문은 다음 장부터 시작한다.
- 순서: 표지 → 첫 문단(`.lead`) + "한눈에" 콜아웃 → 목차 → 본문 구획 → 체크리스트 → 하단 정보.
- 구획 머리는 `.step-head`. 번호나 "1단계" 는 실제로 순서가 있을 때만 붙인다.
- PDF 파일이 필요하면 플레이라이트로 뽑는다: `page.pdf(path=…, print_background=True, prefer_css_page_size=True)`.

## 목록 페이지 (루트 index.html)

계정 섹션과 `<!-- edu:list -->` `<!-- chart:list -->` `<!-- travel:list -->` 표시는 지우지 않는다. 항목은 표시 바로 아래에 이 형식으로 넣는다.

```html
<a class="item" href="chart/apps/position-size/"><b>포지션 크기 계산기</b><span>한 번 틀려도 계좌의 1%만 잃도록 살 수량을 정합니다</span><em>웹앱</em></a>
```

`<em>` 은 자료 종류 배지다: 웹앱 / 대시보드 / 요약서 / 엑셀 / PDF. 빠뜨리면 주소를 보고 자동으로 붙지만 직접 적는다.

## 확인

올리기 전에 플레이라이트(Python)로 찍어서 **직접 본다**.

```python
from playwright.sync_api import sync_playwright
with sync_playwright() as p:
    b = p.chromium.launch()
    for scheme in ("light", "dark"):
        for w, h in ((390, 844), (1280, 800)):
            pg = b.new_context(viewport={"width": w, "height": h}, color_scheme=scheme).new_page()
            pg.goto("file:///…/index.html")
            over = pg.evaluate("document.documentElement.scrollWidth - document.documentElement.clientWidth")
            assert over <= 0, f"가로로 {over}px 넘침"
            pg.screenshot(path=f"check-{w}-{scheme}.png", full_page=True)
```

볼 것:

- 390px 에서 가로로 넘치지 않는다. 표 칸이 어색하게 줄바꿈되지 않는다.
- 제목이 두 줄 이내다. 첫 화면에 표지와 내용의 시작이 함께 보인다(요약서는 표지가 크다).
- 다크 모드에서 글자가 다 읽힌다. 흰 상자가 남아 있지 않다.
- `preview/` 의 같은 견본 화면과 나란히 놓았을 때 한 가족으로 보인다.
- 요약서는 PDF 로 뽑아 첫 장이 표지 한 장인지, 표·코드가 쪽 사이에서 잘리지 않는지 본다.

## 금지 목록

- 그라데이션, 빛 번짐·글로우, 유리 효과, 큰 그림자
- 이모지, 뜻 없는 아이콘, 일러스트, 스톡 사진
- 도장·리본·테이프·종이 질감 같은 빈티지 장식
- 둥근 카드를 줄줄이 늘어놓기, 카드 안의 카드, 카드 왼쪽 색 띠
- 반경 10px 초과, 알약 모양 버튼
- 가운데 정렬 본문. 모두 왼쪽 정렬이다
- 강조색 네 곳 이상, 계정색이 아닌 새 색, 색 글자 제목
- 외부 글꼴·CDN·추적 스크립트
- 표지 구조 변경, 하단 정보 항목 생략
- "완벽", "필수", "꿀팁" 같은 과장 문구와 느낌표 제목
- 견본 숫자·예시 값을 실제 값처럼 보이게 두기
- 개인 계정 이름·실명·이메일·회사·아이 이름
