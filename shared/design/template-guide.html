아이와 30분, 첫 AI 앱

목표는 하나입니다. 아이가 "이거 되네" 하는 순간을 30분 안에 만드는 것. 잘 만드는 건 그다음입니다.

한눈에
  • 준비물은 노트북과 챗GPT 무료 계정, 두 가지입니다.
  • 규칙은 전부 아이가 정하고 부모는 타이핑만 돕습니다.
  • 에러가 나면 아이가 직접 복사해 AI에게 다시 묻습니다.

목차

  1. 뼈대 만들기5분
  2. 아이가 규칙 정하기15분
  3. 에러가 나면7분
  4. 보여주기3분
  5. 끝나고 확인하기체크리스트

1단계 · 5분

뼈대 만들기

챗GPT에 아래 문장을 그대로 넣습니다.

초등학생용 구구단 맞히기 게임을 HTML 파일 하나로 만들어줘.
브라우저에서 바로 열리게 하고, 설명 없이 코드만 줘.

나온 코드를 메모장에 붙여 gugudan.html 로 저장하고 더블클릭하면 브라우저에서 열립니다.

2단계 · 15분

아이가 규칙 정하기

부모가 묻고, 아이가 답하고, 아이가 AI에게 말합니다. 부모가 대신 정해 주지 않는 것이 전부입니다.

부모가 묻는 말아이가 정하는 것
문제 몇 개 낼까?문제 수
틀리면 어떻게 할까?오답 처리
몇 단까지 낼까?난이도
다 맞히면 뭐라고 나올까?끝나는 조건과 보상
시간 제한 둘까?추가 규칙
"5개는 너무 적지 않아?" 라고 말하는 순간 아이 프로젝트가 부모 프로젝트가 됩니다.

3단계 · 7분

에러가 나면

에러 메시지를 아이가 직접 복사해서 AI에게 붙여 넣게 합니다.

이렇게 나왔어. 왜 안 돼?
[에러 메시지 붙여넣기]
주의

부모가 대신 고치면 이 활동의 가치가 절반으로 줍니다. "여기 뭐라고 써 있어?" 하고 화면만 같이 봅니다.

4단계 · 3분

보여주기

완성되면 형제나 친구, 조부모에게 화면을 넘겨주게 합니다. "내가 만든 거야" 라고 말하는 순간이 이 30분에서 아이에게 남는 부분입니다.
